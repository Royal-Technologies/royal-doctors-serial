# Royal Doctors Serial

A WordPress plugin for managing **doctor appointment serials and patient queues**.

**Royal Doctors Serial** is developed by **Royal Technologies** to help clinics, chambers, diagnostic centers, and healthcare organizations manage doctor serial appointments through WordPress.

## About

Managing doctor appointments manually can become difficult when multiple patients need to receive serial numbers throughout the day.

Royal Doctors Serial is designed to provide a structured foundation for managing doctor serials within a WordPress website.

The plugin follows a modular WordPress plugin architecture with dedicated assets, includes, language files, and Composer configuration.

## Installation

### Method 1: WordPress Admin

1. Download the plugin.
2. Log in to your WordPress dashboard.
3. Go to **Plugins → Add New → Upload Plugin**.
4. Upload the plugin ZIP file.
5. Install and activate the plugin.

### Method 2: Manual Installation

Clone the repository:

```bash
git clone https://github.com/Royal-Technologies/royal-doctors-serial.git
```

Copy the plugin directory to:

```text
wp-content/plugins/
```

Then activate **Royal Doctors Serial** from the WordPress Plugins page.

## Development

## Architecture

The plugin uses a modular structure to keep functionality organized.

### `royal-doctors-serial.php`

The main plugin bootstrap file responsible for initializing the plugin.

### `includes/`

Contains the core PHP classes and functionality.

### `assets/`

Contains frontend and admin-side CSS, JavaScript, images, and other static resources.

### `languages/`

Contains translation files for internationalization.

### `composer.json`

Defines Composer dependencies and development configuration.
